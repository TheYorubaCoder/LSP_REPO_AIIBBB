How template pattern used:
The Template Method pattern is implemented in `Report.generateReport()`, which defines the fixed workflow — `loadData()`, `formatHeader()`, `formatBody()`, `formatFooter()` — and is marked `final` so no subclass can reorder or skip steps. The variable steps are declared `abstract` in `Report`, forcing `StudentReport` and `CourseReport` to provide their own implementations without touching the workflow itself. When `Driver` calls `report.generateReport()` on each list element, Java's polymorphism dispatches to the correct subclass implementations of `formatHeader()`, `formatBody()`, and `formatFooter()` at runtime. The parent class owns the skeleton, the subclasses own the details — neither can interfere with the other's responsibility.
